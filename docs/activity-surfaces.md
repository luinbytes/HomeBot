# Activity and artifact surfaces

HomeBot renders provider and tool work as provider-neutral chat activity. The server owns normalization, authorization and artifact paths; desktop and Android receive the same remote-safe protocol projection.

## Normalized activity

An activity has a stable kind (`reasoning`, `search`, `tool`, `filesystem`, `terminal`, `browser` or `artifact`), lifecycle status, risk level and typed presentation detail. File and terminal paths are workspace-relative normalized display paths. Absolute paths, traversal components, platform-specific separators and raw provider payloads are rejected from the client projection.

Typed details cover:

- file action, workspace path, optional byte count and digest;
- terminal command, workspace directory, bounded output preview, exit status and truncation state;
- browser action, URL, title and optional screenshot artifact ID;
- generated artifact ID, safe name, media type and size.

Copy actions use explicit server-provided text. Open actions contain an artifact UUID, never a client-local filesystem path. Risk and `requires_attention` drive visible warning and approval affordances.

## Generated artifacts

Generated bytes are bounded, hashed and stored in the server-owned content-addressed data directory. SQLite stores owner, chat/message/activity relationships, safe display metadata, digest and an internal relative storage path. The public `ArtifactSummary` omits that storage path.

Authenticated clients use:

- `GET /api/v1/artifacts/{artifact_id}` for safe metadata;
- `GET /api/v1/artifacts/{artifact_id}/content` for content.

Both routes are owner-scoped by server authentication. The content route resolves only validated relative server records beneath the configured artifact root. Desktop and Android therefore behave identically over localhost, LAN or Tailscale.

## Desktop behavior

The egui activity card is expandable and presents typed detail, risk state, copy, server-backed artifact open and approval review actions. It never calls a desktop filesystem shortcut. Deterministic visual fixtures cover file, terminal, browser and artifact cards.
